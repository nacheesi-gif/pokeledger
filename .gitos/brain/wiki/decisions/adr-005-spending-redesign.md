# ADR-005 · Focus the same PokéLedger on spending
Accepted 2026-11-17 after the user's explicit scope change.
Keep the logo, sprites, original URL and established financial calculations. Replace primary navigation with Overview, History, Resale and Settings. The user selected Me/Maz/Lalie, receipt splitting and a fresh start with backup.
The new spending ledger uses pokeledger-spending-v1; the previous pokeledger-v1 remains a recoverable raw backup. A first-launch action downloads the previous JSON before initializing the spending ledger. The browser owns file-download confirmation, so retain the original raw data on-device as an additional recovery path. New cloud configuration/session keys isolate the fresh ledger from the old vault until explicitly configured.
Represent one receipt as one purchase with allocations that sum exactly to its amount in integer cents. Legacy purchases without allocations remain readable. Sales, cost basis, unknown costs, fees, shipping, $0 giveaways and cashouts retain established meanings. Market gains do not enter realized profit. Itemized hauls remain available for recorded resale cost basis.
The old gallery/scanner source remains in git for compatibility, but its runtime, camera, price feeds and recurring refresh are outside the active spending interface. Use the supplied neo-brutalist visual reference with a self-hosted OFL Archivo Black display font. No new JavaScript packages, services, account permissions or analytics.
