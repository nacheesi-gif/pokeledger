Status: verified, pending merge to existing `main`. Branch: `gitos-discipline-audit`.

## Evidence
PokéLedger is a multi-module static PWA with historical syntax-only tests and no executable repo-level regression suite. Gitos source recommends evidence-first diagnostics, scope-limited implementation, positive+negative known-answer gates and verification of landed changes.

## Scope
- Adopt Gitos-informed documented project handoff, decisions, module map and work ledger.
- Implement dependency-free Node checks for current source and essential pricing, ownership, browser-cache and restock behavior.
- Add GitHub CI checks and an operator-friendly README section.
- Preserve existing app and records; do not bundle Gitos's Claude-dependent Python runtime.

## Out of scope
Rewriting all feature modules at once, live device measurements, paid feeds, third-party service installations, any migration or clearing of local user data.

## Acceptance
- Parse every production script and inline app JavaScript.
- Positive and negative price-freshness checks.
- Positive and negative owned inventory / save checks.
- Positive and negative cache routing tests.
- No test runner dependencies; all tests pass before merge.
- Exact diff and branch reviewed before integration.
