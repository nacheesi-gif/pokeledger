# WO-015 · Editable cashouts, overall cash P&L and matching sprites
Research: inspected current cashout form, metrics, receipt allocation model, persisted snapshots, rollback writes and resale costs. Existing active cashout form only creates records. Dashboard shows realized sale profit but omits payouts and overall spending. Reuse existing integer-cent validation and atomic LedgerUI.write; no new dependency, permission or financial data provider.
Scope: edit all cashout fields while retaining ID/extra metadata. Overall cash P&L all-time = sale amount less fees/shipping + cashouts received less all purchase totals. Do not subtract sale cost basis again because purchases already count. Keep realized sale profit unchanged; exclude unsold market value. Include historical payouts by default, provide explicit sale-transfer classification to prevent duplicate income. Transfers exclude the cashout entirely; any extra withdrawal fee should be recorded in sale fees. Old records remain unchanged until edited.
Tests: known positive/negative/zero/decimal totals, mixed allocations counted once, unknown sale basis, duplicate-transfer exclusion, edit identity/inventory retention, invalid data and quota rollback. Browser check edit/reload/dashboard/mobile widths; verify exact deployed assets.
User sprite scope: use the same Gen3 icon set as existing app, replace Eevee with Gyarados; retain Me Charizard and existing family identities. Source review and final sprite implementation evidence below.

## Sprite source decision and implementation
- User clarified to use the existing source set. All 386 standard Gen 3 species icons are bundled as one 135,247-byte transparent static atlas, replacing repeated requests. No animation, API lookup or runtime dependency; shell-cached offline.
- Source: PokeAPI/sprites, pinned commit `c0542f7c51215d9672439012838c99f520596cbd`, `sprites/pokemon/versions/generation-iii/icons/{id}.png`. Repository active (last push 2026-11-13), not archived, LICENCE.txt inspected: CC0 repository dedication; all image contents copyright The Pokémon Company. No auth or paid service.
- Species names snapshot: PokeAPI/pokeapi `data/v2/csv/pokemon_species.csv`, first 386 IDs. Local map; no runtime metadata requests. Build script uses existing development Pillow only; production stays dependency-free.
- Gyarados replaces active Eevee home/welcome/default placement; Me remains Charizard. Recognizable species in image-free history/sales use matching icons; generic purchases retain profile defaults and cashouts retain Umbreon.
- Cashouts edit in place through atomic validated writes, preserving IDs and unrelated fields. Payout versus already-recorded-sale transfer classification avoids double-counting. Legacy cashouts count as payouts until explicitly reclassified. Overall cash P&L is all-time and separate from realized sale profit.
