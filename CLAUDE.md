# PokéLedger development context

Read `AGENTS.md` first. The repo uses the `gitos-discipline` skill in `.agents/skills/gitos-discipline/SKILL.md` and the durable project record in `.gitos/`.

Every meaningful change follows: evidence → scoped work order → implementation → positive & negative tests → verified landing.

The repository is an existing personal-use PWA, not a new product. Preserve `pokeledger-v1` local data and its backups. Do not install upstream Gitos Python services, optional local models or additional dependencies without reviewing them. CI checks are the release gate.

This is an adaptation of https://github.com/wizzo-gmb/gitos (MIT © 2026 Wizzo), not an installation of its full engine.
